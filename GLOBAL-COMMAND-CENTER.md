# Global Institute Command Center

## Operating modules

1. Organization directory
2. Organization onboarding
3. Verification queue
4. Regional coordination
5. Program management
6. Project exchange
7. Partnership matching
8. Volunteer coordination
9. Impact reporting
10. Document center
11. Governance and audit

## Verification statuses

- self_declared
- submitted
- under_review
- verified
- partially_verified
- expired
- rejected

The interface must display exactly what has been verified. Avoid generic labels such as "government approved" or "internationally accredited" unless supported by authoritative evidence.

## Regional model

Use a region/country taxonomy rather than assuming one global regulatory regime:
- Africa
- Asia-Pacific
- Europe
- Middle East
- North America
- Latin America & Caribbean

Country-specific compliance should be handled by the participating entity and its professional advisers where required.

## Partnership lifecycle

Discover → Request introduction → Review → Due diligence → Agreement outside/through approved workflow → Active collaboration → Reporting → Closeout

## Impact lifecycle

Project definition → Baseline → Activities → Outputs → Outcomes → Evidence → Review → Published summary

## Sensitive data

Beneficiary-level personal information, health information, precise vulnerability data, financial account credentials and other sensitive information must not be published in the public directory.
